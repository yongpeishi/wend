# Roadbook — mobile

The finished plan, read while walking. 390×844. The day in progress inverts to deep leaf for outdoor reading; the browsing screens stay on paper.

- `Phone.jsx` — 22px screen surface, status line, three-tab bar with stop dots
- `TodayScreen.jsx` — the inverted hourly plan, apricot ring on where you are now
- `DaysScreen.jsx` — the six days, today ringed in apricot
- `KeptScreen.jsx` — the shortlist, filterable, still keepable and unkeepable
- `data.js` — the sample trip

Composed from the system's own components. These screens are new compositions following the documented rules, not recreations of an existing Wend interface.
