One-line: section and metadata labels — 12px bold, 0.12em tracking, uppercase; use it instead of a small heading.

```jsx
<Label as="h2" tone="strong">Day three · Kyoto</Label>
```

Tones: `muted` (default), `strong`, `onDark` for deep-leaf surfaces. Never set a label in straw — straw is a shape, not a text colour.
